# ETHGlobal Mumbai checklist

These are taken from the official event pages: the rules page and the prizes page, snapshotted 5 Nov 2026.

## Deadlines (IST)

- [ ] Submit by **Sat 7 Nov, 09:00**. Late submissions are not accepted.
- [ ] Have the demo video recorded by Sat 07:00.
- [ ] Judging runs 09:30–12:30 Sat. A finalist presentation is 4 minutes of demo plus 3 minutes of Q&A.

## Rules

- [ ] Classic track: every line of project code was written after Thu 5 Nov 21:00. Public libraries are allowed and are listed in the README.
- [ ] Steady commit history. No single big upload at the end.
- [ ] README section on AI usage: which parts were generated or assisted by AI.
- [ ] Spec-driven workflow: the planning artifacts are in the repo (`docs/plan.md`, `docs/decisions.md`).

## Submission form

- [ ] Title, description and repo link.
- [ ] Partner prize: EF "Best use of the Frame Transaction Alternative Mempool". Explain how we used it, and give feedback.
- [ ] Optional demo video: 2–4 minutes, 720p or better, real narration (no AI voice), not sped up, not recorded on a phone.

## EF alt-mempool prize qualification

- [ ] A link to our admitted transaction on the devnet explorer, or code that submits one.
- [ ] We can explain the design, the code and the trade-offs. See `docs/architecture.md`.
- [ ] Judging criteria: creativity, usefulness, practicality, how well it works, and relation to the alt mempool.
